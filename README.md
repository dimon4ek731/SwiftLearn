# SwiftLearn

Нативное iOS-приложение для профессионального изучения языка Swift 6 и фреймворка SwiftUI: интерактивный учебный курс с практикой написания кода в каждом уроке, защита от хардкода (Anti-Cheat), банк олимпиадных задач (LeetCode и Codeforces), встроенная полнофункциональная официальная документация Swift 6 и мобильная среда разработки (IDE).

---

## Ключевые возможности приложения

### 1. Учебный план (50 уроков Swift Core и SwiftUI Pro)
- **Полная спецификация языка Swift 6**:
  - Типы данных, операторы, опционалы, коллекции, замыкания, ООП/ARC, дженерики, протоколы, Swift Concurrency (`async/await`, `actor`, `Sendable`).
  - Архитектура SwiftUI: иерархия View, Data Flow (`@State`, `@Binding`, `@Observable`), анимации, жизненный цикл и кастомные модификаторы.
- **Интерактивная практика написания кода в каждом уроке**:
  - В каждом уроке встроен полнофункциональный редактор кода с подсветкой синтаксиса Swift 6 и точной нумерацией строк.
  - Автоматическая проверка через встроенный интерпретатор с набором unit-тестов.
  - Урок считается пройденным только при успешном прохождении всех тест-кейсов.
- **Система защиты от хардкода (Anti-Cheat & Code Integrity)**:
  - Статический анализатор проверяет обязательное использование входных параметров функции и блокирует возврат захардкоженных констант.
  - Динамические стресс-тесты со случайными входными данными предотвращают подгонку ответов через условные конструкции `if/else`.

### 2. Официальная документация Swift 6 (Вкладка «Доки»)
- **Режим docs.swift.org (Web)**: встроенный нативный веб-движок на базе `WKWebView`, транслирующий официальную документацию The Swift Programming Language точ-в-точ как на сайте с навигацией и поиском.
- **Офлайн-ридер**: полный структурированный справочник книги (Welcome to Swift, Language Guide, Language Reference) с поддержкой мгновенного поиска, переключения языков (RU/EN) и регулировки шрифта.

### 3. Банк алгоритмических задач (118 задач LeetCode и Codeforces)
- Категории: *Easy*, *Medium*, *Hard*, *LeetCode*, *Codeforces*.
- Темы: массивы, строки, бинарный поиск, стек/очередь, скользящее окно, два указателя, динамическое программирование, структуры данных.
- Проверка кода через тестовые наборы с подробной детализацией входных данных и ожидаемого вывода.

### 4. Встроенная среда разработки (Swift IDE)
- Редактор кода с подсветкой синтаксиса Xcode Dark, номерами строк и отступами.
- Запуск произвольного Swift-кода с выводом в консоль.
- Диагностический анализатор распространенных ошибок и антипаттернов.

### 5. Двуязычный интерфейс и профиль
- Полная локализация на русский и английский языки (RU / EN) с переключением на лету.
- Профиль разработчика: статистика решенных задач, освоенных уроков, уровни, серия дней (Streak) и начисление очков опыта (XP).

## Архитектура и стек технологий

- **Язык**: Swift 6 (Strict Concurrency ready)
- **UI Framework**: SwiftUI (100% декларативный нативный интерфейс)
- **Target OS**: iOS 17.0+ (поддержка iPhone и iPad)
- **Редактор кода**: TextKit 1 + UIKit (`UIViewRepresentable`) с кастомной отрисовкой номеров строк
- **Веб-движок**: WebKit (`WKWebView`)
- **Генератор проекта**: `xcodegen` (`project.yml`)
- **Хранение данных**: `UserDefaults` / `StorageService`

---

## Инструкция по сборке и запуску

1. Убедитесь, что установлен Xcode 15+ и утилита `xcodegen`:
   ```bash
   brew install xcodegen
   ```

2. Сгенерируйте файл проекта `.xcodeproj`:
   ```bash
   xcodegen generate
   ```

3. Откройте проект в Xcode:
   ```bash
   open SwiftLearn.xcodeproj
   ```

4. Выберите целевой симулятор (например, **iPhone 17 Pro**) или подключенное физическое устройство и нажмите **Cmd + R** (Run).
